# Number Game

記錄一些適合練習觀察力、反應力與數字辨識的小遊戲。

這個專案使用純 HTML、CSS、JavaScript 製作，不需要額外安裝套件，打開瀏覽器即可遊玩。畫面支援桌機與手機，適合小朋友練習數字順序、隨機指定數字辨識，也可以開啟「計時挑戰」模式增加遊戲挑戰性。

## Demo

* 遊戲首頁：https://druidcub.github.io/number-game/

## 遊戲列表

### 順序點

依照數字順序從 `1 → 2 → 3 ...` 點完全部格子。

特色：

* 可調整遊戲大小 `n × n`
* 數字位置每次隨機排列
* 點對會有成功音效與顏色提示
* 點錯會提示下一個正確數字
* 完成後有煙火動畫
* 支援「計時挑戰」

### 隨機點

每一回合由題目隨機指定要點擊的數字，玩家需要在畫面中找到該數字並點擊。

特色：

* 每次題目隨機指定數字
* 點對後自動抽下一個目標
* 已完成的數字會鎖定
* 可調整遊戲大小 `n × n`
* 完成後有煙火動畫
* 支援「計時挑戰」

## 計時挑戰

遊戲提供「計時挑戰」選項。

勾選後：

1. 從第一次正確點擊開始計時
2. 遊戲完成後自動停止計時
3. 完成訊息會顯示本次挑戰用時

這個模式適合用來挑戰自己的速度，也可以和家人朋友比賽誰完成得更快。

## 技術特色

* 純前端實作
* 不需後端服務
* 不需建置工具
* 支援手機與桌機版面
* 使用 CSS Grid 建立遊戲格子
* 使用 Web Audio API 播放提示音效
* 使用 JavaScript 控制遊戲流程、隨機排序、計時與完成動畫

## 使用方式

將專案 clone 到本機：

```bash
git clone https://github.com/druidcub/number-game.git
```

進入專案資料夾：

```bash
cd number-game
```

直接用瀏覽器開啟 `index.html`，或使用簡單的靜態伺服器：

```bash
npx serve .
```

接著開啟瀏覽器進入：

```text
http://localhost:3000
```
